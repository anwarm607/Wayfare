# Nunito Sans

Source: [Google Fonts Nunito Sans](https://github.com/google/fonts/tree/main/ofl/nunitosans), downloaded 22 October 2026.

The four static TrueType files were generated from Google's `NunitoSans[YTLC,opsz,wdth,wght].ttf` using fontTools 4.67.0. Each file pins every variable axis: width 100, optical size 12, lowercase height 500, and its requested weight. These are the source's standard named-instance settings.

| File | Weight | Verified internal PostScript name |
| --- | --- | --- |
| NunitoSans-Regular.ttf | 400 | NunitoSans-Normal |
| NunitoSans-SemiBold.ttf | 600 | NunitoSans-NormalSemiBold |
| NunitoSans-Bold.ttf | 700 | NunitoSans-NormalBold |
| NunitoSans-ExtraBold.ttf | 800 | NunitoSans-NormalExtraBold |

The files have been reopened and checked: each has the correct `OS/2.usWeightClass` and no remaining `fvar` table. Use explicit font-family aliases when wiring them into Expo; do not assume the filename matches the internal family name.

The original SIL Open Font License is included in `OFL-NunitoSans.txt`. No font package or app dependency was installed.
